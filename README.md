# DSCI 522 Dockerfile Practice

A reproducible Jupyter + Python data science environment using Docker and conda-lock. Created as an individual assignment for DSCI 522, Data Science Workflows, in Fall 2025 by Claire Saunders. 

This project demonstrates:
- Locked dependencies for reproducible builds across platforms
- Automated Docker image publishing via GitHub Actions
- Best practices for containerizing Python environments

To build locally: `docker build -t dsci522-dockerfile-practice .`
